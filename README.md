# WAEKIUM
### Sistema Integrado de Gestão de Transportadoras

**React · React Native · Python · Flask · SQLite**

Projeto acadêmico de desenvolvimento full stack, apresentado no **TechDay da UniMAX**.

---

## Sobre o projeto

O **Waekium** é um sistema integrado de gestão de transportadoras, desenvolvido para centralizar processos administrativos, financeiros e operacionais do setor logístico.

A solução combina uma aplicação web, um aplicativo mobile e uma API backend, explorando a integração entre diferentes tecnologias para facilitar o gerenciamento de informações e atividades de uma transportadora.

O projeto foi desenvolvido de forma colaborativa como parte das atividades acadêmicas e apresentado no TechDay da UniMAX.

## Funcionalidades

- **Gestão de colaboradores:** cadastro e gerenciamento de usuários.
- **Controle financeiro:** acompanhamento e organização de informações financeiras.
- **Monitoramento de motoristas:** acompanhamento de motoristas em suas rotas.
- **Reconhecimento facial:** funcionalidade de autenticação por reconhecimento facial.
- **Controle de ponto:** registro e gerenciamento das jornadas de trabalho.
- **Integração multiplataforma:** comunicação entre as aplicações web, mobile e backend.

## Arquitetura

O Waekium utiliza uma arquitetura dividida em três componentes:

**Aplicação Web:** interface para utilização das funcionalidades administrativas e operacionais.

**Aplicativo Mobile:** interface para acesso às funcionalidades em dispositivos móveis.

**Backend:** camada responsável pelo processamento de requisições, implementação das regras de negócio e persistência de dados.

Essa organização permite separar responsabilidades e facilitar a manutenção e evolução do sistema.
